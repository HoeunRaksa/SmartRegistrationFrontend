# DashboardAdmin

DashboardAdmin is a modern web-based admin dashboard developed using **ReactJS** and **Tailwind CSS**. The application provides interactive analytics, data visualization, and management interfaces designed for responsive and scalable administration systems.

The project focuses on clean UI/UX, responsive layouts, reusable components, and real-time dashboard experiences.

# Installation

Clone repository:

```bash
git clone https://github.com/your-username/DashboardAdmin.git
```

Move into folder:

```bash
cd DashboardAdmin
```

Install packages:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build production:

```bash
npm run build
```
